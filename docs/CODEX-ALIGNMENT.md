# 本机 Codex 对齐记录

早期对齐依据用户授权检查的 Codex 26.930.2377 安装包，0.5.0 的过程状态与布局复核使用本机 26.930.3930。下列是资源摘要与可观察参数，不分发 Codex 应用脚本或样式代码。

## 文件与结果

- `codex-spritesheet-v6-51045ae208c0.webp` 及另外八张内置图集，与本仓库现有图集逐字节一致；无需重新替换图片。
- 图集几何为 1536×2288，8 列、11 行，每帧 192×208；旧版为 9 行。最后两行提供 16 个方向的视线。
- 动画参数位于 `app-initial-1da99842592d.js` 的图集播放器；原生浮窗组合位于 `avatar-overlay-native-page-4ac6f8c4fe13.js` 与 `avatar-mascot-button-dfaa448984b1.js`。
- 原版待机帧时长为基础值的 6 倍。普通状态先播放三个周期，然后回到慢速待机；并非始终循环运行/完成动作。
- 待机、运行、挥手允许方向帧，目标点死区为 1 个界面像素。进一步核对调用处发现：方向目标来自输入光标、通知回复光标或 `avatar-overlay-computer-use-cursor-changed`，不是全桌面普通鼠标。0.2.3 移除普通鼠标跟随，并在浮窗输入框获得焦点时跟随其输入光标；尚未连接 DSH computer-use 的操作位置。
- 悬停优先播放跳跃；横向拖动超过 4 个界面像素才选择左右移动动作。
- 绘制使用像素化采样，帧宽高比例固定为 192:208。

## 界面测量

输入区使用浏览器单行输入，不使用 WinForms 多行编辑控件。参考实现的输入文字为 14px/18px，圆角约 24px，发送/附件按钮为 28px，通知最小高度为 56px，任务操作按钮为 32px。

本 fork 独立实现透明 HTML 浮窗、CSS 字体/阴影、SVG 按钮和动画状态机。展开新对话时收起工具条，以单行胶囊承载输入；点击外部或窗口失去焦点时收起，保留草稿和附件。附件选择器暂时获得焦点时不收起输入框。保留通知、原始请求身份和宿主权限验证。

0.2.4 按用户补充截图对齐：工具条悬停展开，无任务时仅新对话和语音；有任务时增加折叠按钮。宠物位于工作区下半部时通知在上方，上半部时在下方，窗口尺寸变化保留宠物锚点。通知标题后展示助手可见文字摘要，完成时增加勾选标记；悬停出现操作，回复展开内嵌跟进输入框。跟进经 DSH 原会话的 prompt queue 提交，不创建新会话。DSH 工具名只作为工具活动回退文字，不把它包装成 Codex 特有的工具摘要。

## 运行与边界

### 2026-10-03 行为审阅

| 场景 | 本地 Codex 逻辑与本 fork 处理 |
| --- | --- |
| 无任务 / 空闲 | 六倍帧时长的慢速待机循环；移除页内每 18 秒的随机挥手/跳跃。 |
| 工作中 | running 行播放三轮后进入慢速待机；这是原版默认 loop=false 的逻辑，保留。 |
| 完成 / 失败 / 等待输入 | review / failed / waiting 各自播放三轮后待机，通知和任务状态继续保留。 |
| 多任务 | 需要输入、失败、完成、运行的优先级维持 0/1/2/3；状态通知不被动画互动改写。 |
| 悬停人物 | jumping 覆盖基础状态；离开后恢复该状态并重新开始播放。 |
| 拖动 | 左/右移动动作优先于悬停；结束、捕获丢失、Esc 等路径清理临时动作。 |
| 新聊天 / 跟进输入 | idle、running、waving 允许方向帧；两种输入框都测量实际光标，跟进框支持换行与滚动。 |
| 退出光标跟随 | 重启动画计时，不在静态方向帧显示期间耗掉三轮动作。 |
| 减少动态效果 | 每个状态使用第一帧；输入方向帧仍允许变化，与参考播放器的 lookFrame 优先处理一致。 |
| 双击 | 去掉本 fork 额外的强制 2.1 秒跳跃，避免覆盖任务或后续拖动状态。 |
| 审批结束 / 更新 | 只显示最新会话、轮次和请求身份的面板；结束后立即关闭，同一请求的问题内容变化时重建表单。 |
| 折叠通知 | 关闭请求面板与当前新聊天，保留未发送草稿；不提交审批，也不停止后台任务。 |
| 本地语音待机 | ready / standby / waking 可录音，由 DSH 宿主唤醒识别工作进程。 |

此次检查不把尚未接入的能力描述成已复刻：原版头像单击可将 Codex 主窗口拉到前台，DSH 当前公开桌面桥没有对应接口；0.5.0 为任务卡显式点击加入独立 Windows 前置路径，仍不改变头像单击行为。Codex 首次唤醒欢迎通知、GPT-Live 原生实时语音模型、computer-use 操作位置联动及原版甩动惯性均尚未实现。

0.3.0 根据用户的费用约束增加本地连续通话：SenseVoice 本地分段识别，绑定原会话进行 DSH 文字任务，Windows System.Speech 在内存生成 WAV，再由浏览器播放。它提供连续收音、自动发送、语音摘要、播放打断及本地控制，保持模型/权限/审批归 DSH 所有；不是 GPT-Live 的音频原生推理或独立语音协调 Agent。

打断只取消语音生成/播放，普通新指令由原生 steer 路由；“停止当前任务”才调用目标的 cancel。挂断、断线、页面卸载和目标移除停止音频并释放引用，不重放消息或改用另一会话。声音、语速可配置，所有新脚本随包分发，不执行安装时编译或下载。

0.2.8 语音就绪规则与 DSH 官方 `dsh-experimental-client-ui-voice-input` 对齐：ready、standby、waking 均可录音。SenseVoice 启动时只检查缓存，验证成功进入 standby；空闲也会释放工作进程回到 standby，转写时自动唤醒。此前仅允许 ready 导致已安装模型仍显示准备提示。本 fork 不主动调用 prepare 或重新下载模型，不绕过宿主的转写队列和取消机制。

0.2.7 新对话图标使用本地 `square-and-pencil-light-20` 的两段填充路径与 20×20 viewBox，保留 currentColor 以支持浅色/深色主题；其素材权利声明补充至 NOTICE。

0.2.6 再核对原生窗口布局与主题参数：原版以宠物帧本体约束横向位置，而透明绘制窗口可跨出显示器；消息另设 12px 边距。纵向使用工作区顶部到显示器底部（含任务栏区域），底部保留 8px 与 32px 工具区，取代本 fork 曾用的 96px。DSH 的透明画布独立扩为 768px，保证卡片向内偏移后不被自身窗口裁切；宠物大小仍尊重已有设置。

早期折叠控件曾误把单个参数 17×6px 当作总尺寸（0.5.4 更正为 23.5×6px）、圆角 6.5px、折叠延迟 300ms；鼠标接近/离开阈值 40/56px。回复按钮为 32px、20px 肘形回转箭头；浅色默认底色 #e8e8e8、图标 #9f9f9f，悬停底色 #afafaf、图标白色；输入框底色 #dfdfdf、圆角 24px、行高 16px。参数按本地参考重写，未分发原应用的窗口管理器或会话代码。靠底部时输入面板翻到宠物上方，避免新增聊天输入框缩小宠物移动范围。

0.2.5 修复独立浮窗的拖动结束缺口：DOM 捕获丢失、取消、全窗口抬起、失焦和 Esc 均清理拖动；主进程同时检查鼠标释放与 Windows 捕获/取消消息，不再只依赖宠物节点上的 pointer-up。单次拖动上限 30 秒。窗口层使用公开的 [Electron Windows 消息接口](https://www.electronjs.org/docs/latest/api/base-window#winhookwindowmessagemessage-callback-windows) 和 [鼠标事件接口](https://www.electronjs.org/docs/latest/api/web-contents#event-before-mouse-event)，不安装全局鼠标钩子。

浮窗使用用户配置的 Electron 可执行文件或 `~/.dsh/electron` 共享运行时，不引用其他宠物插件的应用代码。Windows Electron 无法可靠读取 piped stdin，父进程向浮窗发送消息改为随机令牌认证的 loopback 连接；子进程事件保留 stdout JSON，断线与父进程退出时关闭窗口。

Codex 原版顶部语音入口包含原生实时语音会话能力。DSH 本 fork 的本地连续通话和右键语音转文字分别提供自动发送与手动发送路径，不声称音频模型和交互延迟完全复刻。图片的原始权利声明仍见 NOTICE。


0.4.0 新增独立文字模型语音对话层：沿用 DSH 当前会话模型（新对话用默认模型），工具为空，与执行 Agent 隔离模型游标。闲聊和澄清直接生成短口语；工作请求通过原 Session 输入，任务事实再组织成口语摘要。结果读取有界完整可见回复而非通知卡片的 500 字预览，保留失败/取消状态。澄清上下文仅用于解释原始请求，不赋予额外权限。临时对话上下文在挂断后清理，任务及审批仍归原 Session。此为 ASR → 文字语音层/执行 Agent → TTS 的分段架构，尚不是 GPT-Live 的原生音频模型；识别/播报本地，对话按既有文字模型用量计费。

## 0.5.0 过程反馈与任务入口（2026-10-03）

对照 Codex 26.930.3930 的普通会话通知，标题与 Thinking 后备文案分为上下两行；Codex 另有内联活动类型，本轮不把所有通知强制合为一行。中文状态采用“正在思考”“需要输入”“就绪”“已拦截”。DSH 通过自己的公开 step、assistant/live-chunk、tool/call、tool/result 与 compaction 边界投影阶段，读取可见文字，忽略推理正文、工具参数和结果。工具活动按本地工具名给出说明，保留并行调用，最后一个工具结束后回到思考；没有事件依据时不编造重试或进度。

新建宠物任务调用原 Session create，并显式传入插件创建的独立工作目录；不传入权限覆盖，已有会话跟进保留原目录。Codex Quick Chat 的 projectless 入口作为行为参考，DSH 工作目录由本插件独立分配。

导航优先调用 uiWorkspace.openSession，Sessions.open 仅作旧宿主回退。原生任务卡等导航成功后才请求窗口前置；独立 Win32 帮助脚本仅沿持有插件的进程祖先查找官方 DSH 窗口，并复核 HWND/PID/启动时间，不按窗口标题查找其他进程。只在显式点击时恢复/前置，不设置永久置顶；失败如实提示。正常和最小化的专用测试窗口通过前置检查，缺少所属窗口时拒绝全局回退。

## 0.5.1 语音结果去重与网页增量上下文（2026-10-03）

用户截图中同一份任务回复先以 outcome 未定义发送一次 result，随后补上 completed 又发送一次。这来自语音控制器把回复标识和结束状态拼成去重键，不能据此判定为模型缓存重放。现代事件窗口现在等待 turn/end；兼容路径忽略相同回复的迟到 completed 元数据，同时保留取消、失败和新轮次身份。

语音模型改用真正的 user/assistant 消息前缀，历史不再嵌在每个新用户 JSON 中；已提供的相同任务正文用 replyUnchanged 标记引用。历史按完整交流轮次和正文长度约束，裁剪时去掉旧任务正文并更换独立网页游标，使被删减的前缀不会继续叠在旧网页会话上。挂断清空历史。使用真实 Web API dsh-web-codec 的隔离对照确认第二轮只发送一条新 user 消息，之前的 assistant 被正确确认；没有修改 Web API 插件，也没有使用真实账号或麦克风。

### 2026-10-06 折叠总尺寸与边界位置复核

0.5.4 只读核对本机 Codex 26.930.3930 安装包的控件几何与原生宠物布局。此前 17px 是单个 compactControlWidth，两个控件重叠后实际总宽为 17×2−10.5＝23.5px，高 6px；两／三按钮行宽为 80／120px。带宠物的新聊天框限制在屏幕内 16px，宽为 min(330, 屏幕宽−32)，按钮行以宠物中心为初始位置并约束到该框；折叠围绕完整按钮行的中心收缩，所以靠边时底条也随之内移，不按 23.5px 单独重新居中。两种状态的顶部均在宠物帧下方 4px。

DSH 独立实现该几何计算，主进程在放置、拖动和尺寸变化时更新工具条偏移；消息卡片仍使用自己的边距。渲染层保留偏移中心，悬停区域包含偏移后的工具条，ResizeObserver 在尺寸过渡中同步真实点击区域。隔离原生验收覆盖 64／120／224px 宠物、左右边缘、两／三按钮、折叠前后同一中心以及三个按钮的实际鼠标点击；语音只验证命令送达测试宿主，不录制或播放真实音频。私有参考资源仅用于本地研究，不打包。

补充纵向核验：当前新聊天按钮行高 40px，加底边 8px，宠物帧底部需保留 48px；旧版按 32px 控件行保留 40px 已不足。0.5.4 使用 48px，四角实际浮窗验收确认展开栏底部仍有 4px 留空，宠物位置不随展开／折叠变化。
