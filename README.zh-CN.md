# DSH 悬浮宠物

这是 [MichengAI/dsh-codex-pet](https://github.com/MichengAI/dsh-codex-pet) 的独立 fork，基于上游 0.1.12。新增 Windows 原生透明浮窗，让宠物能显示在 DSH 窗口之外。当前 fork 版本为 **0.4.0**。

## 功能

本轮根据本机 Codex 26.930 安装包中的实际动画参数与界面尺寸对齐；记录见 [本地对齐说明](docs/CODEX-ALIGNMENT.md)。图集一致，修正的是播放节奏、动作优先级和绘制方式。

- 工具条平时收成小胶囊，悬停时展开；无任务时只有新对话和语音两个按钮，有任务时增加折叠/展开按钮与通知数量。
- 宠物靠屏幕下方时消息放上方，靠上方时放下方；输入框和通知展开时保留宠物位置。通知显示可见回复摘要或当前工具名，完成时显示勾选标记；悬停显示回复、停止和关闭操作，回复可直接输入“继续跟进”，发送到原会话。
- 新对话打开浮窗输入框，点击发送或 Ctrl+Enter 后才创建 DSH 对话。语音按钮开始本地连续通话：稍作停顿后自动把识别文字发送到绑定会话，并朗读新的回复摘要；再次点击或按红色电话按钮挂断。右键宠物 → 语音转文字保留原来的手动发送方式。
- 独立语音对话层沿用所选 DSH 文字模型：闲聊、追问与澄清直接口语回答，工作请求才交给原任务；结果先整理为一至三句口语，详细目录、文件和日志保留在原对话。不会截取回复开头当作摘要，识别过程中可继续补充或改口。
- 识别与播报仍在本机，无需新增语音 API Key。语音对话会增加普通文字模型调用，按已配置模型的使用方式计费；语音层没有工具和审批权限。通话内的简短交流上下文在挂断后清理。
- 本地识别器的待机状态也可录音，转写时由 DSH 自动唤醒；无需每次启动后重新准备已安装的模型。

- 宠物独立置顶显示；切换应用、离开或最小化 DSH 后仍可见。启动和状态更新不抢占焦点。
- 宠物背景透明，透明像素处不挡鼠标。按住左键拖动可移动位置，松开或按 Esc 结束；捕获丢失和窗口失焦时也会停止，单次拖动最多 30 秒。悬停时播放跳跃动作，右键打开菜单。
- 保留 9 只内置宠物、自定义宠物、动画及任务通知。通知可以打开关联会话、停止当前轮次、关闭提醒和回答支持的审批、问题与计划请求。
- 桌面位置按显示器保存，支持 DPI 缩放和负坐标显示器；显示器移除时回到主屏。拖动时按当前显示器限制宠物位置。
- 拖动范围按宠物本体计算，可靠到屏幕左右与顶部边缘；底部保留工具区。通知和输入面板单独避让边缘，透明绘制区域不挡鼠标。
- **设置 → 悬浮宠物 → 外观 → 桌面悬浮** 可切换桌面或页内显示。右键菜单也可返回页内显示、收起宠物或打开设置。
- 浮窗成功绘制后才接管显示；进程故障时恢复页内宠物。关闭 DSH、卸载插件或显示页面断开后，浮窗自动关闭。

## 运行环境

桌面浮窗当前支持 **Windows 10/11**，使用独立透明 Electron 浮窗与浏览器绘制。不修改官方 DSH 安装文件，不依赖 MichengAI 的桌面分支。优先复用 `~/.dsh/electron/electron.exe`，或用 `DSH_FLOATING_PET_ELECTRON` 指定通用 Electron；缺少运行时时恢复页内显示，不自动下载。

保留上游声明的 DSH RC 兼容名单；开发基线和当前验证目标为 **DSH 0.2.0-rc.2**。Linux/macOS 保留页内宠物，本 fork 尚未实现这两个平台的原生浮窗。退出整个 DSH 后宠物关闭；它不是独立运行的任务代理。

## 本地连续通话

需启用官方 DSH 语音输入，并在其设置中准备 **本地 SenseVoice**。Windows 已安装的系统声音用于回复，**不需要语音 API Key，不新增语音 API 费用**；DSH 的文字模型仍按你的原配置运行和计费。没有本地识别器时提示设置，不自动改用云识别或下载模型。

1. 在 DSH 中选择要交流的对话，然后点击宠物的语音按钮；首次使用允许麦克风访问。
2. 面板显示绑定对话、收音状态、最近识别文字和语音回复。说完停顿约一秒，文字自动提交；没有当前对话时，仅在第一句普通消息后创建新对话。
3. 运行中指令使用 DSH 原生 `steer`，空闲时使用 `queue`；沿用该会话的模型、工作区与权限。切换主界面对话不会悄悄改变通话目标，需挂断后重新开始。
4. 再次讲话会打断播放，后台任务继续。麦克风按钮暂停/恢复收音；挂断释放麦克风和观察引用，不取消任务。关闭页面、连接丢失或目标会话被移除时结束通话。

可直接说“查询进度”“停止当前任务”“再说一遍”“别说了”“结束通话”。这些是当前通话的本地控制指令；普通文字进入 DSH 会话。审批或问题仍在原对话/宠物请求面板中处理，不会通过语音自动批准。

**设置 → 悬浮宠物 → 本地语音通话** 可选择系统声音和语速。录音片段只由宠物插件在内存中缓存，单句上限 30 秒；超长句不作为截断指令发送。每次最多待处理两句。语音回复朗读短摘要，代码和完整结果仍查看原对话。

这是本地分段识别＋DSH 文字任务＋系统朗读，延迟、声音自然度与 ChatGPT/GPT-Live 的原生实时语音模型不同；没有额外的实时语音模型或后台语音 Agent。

## 安装

此 fork 通过 GitHub 推送分发，不发布 npm 或 GitHub Release。`lib/` 已构建并提交，插件自身没有安装阶段构建脚本：

```powershell
dsh plugin --profile desktop add 'https://github.com/Very12345/dsh-codex-pet.git' --ignore-scripts
```

如原先装过 `@michengai/dsh-codex-pet`，请先移除上游包，再安装 fork；两个版本使用同一资源路由，不应同时启用。另一款 `dsh-pet` 蓝鲸插件可继续保留，本 fork 以“悬浮宠物”单独显示。已有宠物和显示偏好保留在 `.dsh/codex-pet`。桌面模式默认开启，安装后重启 DSH。

如果没有 `dsh` 命令，请通过官方 DSH 的插件安装入口使用上述 GitHub 仓库地址。设置页 GitHub 按钮指向本 fork；更新时重新安装仓库最新版，避免用上游 npm 更新覆盖浮窗实现。

## 交互与边界

任务通知来自原生 DSH 会话快照，浮窗通过 SSE 接收并回传操作。审批和跟进保留原会话、轮次和请求标识，仍由宿主验证；不会自动批准或更改权限。摘要只读取宿主公开事件中的可见助手文字和工具名，不显示推理内容与工具参数。缺少相关事件的旧宿主回退到状态文字。既有会话跟进使用原会话的 queue 提交模式，不创建新的对话。

桌面模式一次由一个 DSH 页面接管。切换窗口或最小化不会释放接管；页面真正关闭、刷新或连接中断时保留最多 10 秒重连时间，再关闭浮窗。重新加载页面可重新创建。关闭或操作失败后，可在设置中关闭再开启桌面悬浮重试。

图集按需在内存中转成 PNG，使用像素化采样、慢速待机及三轮状态动作后回到待机，原始文件和自定义宠物不改写。会话观察引用仅在任务运行或等待交互时保留，停止和卸载时释放，避免占用已停止对话。

已验证 82 项自动化测试、页内通知与中英文界面、Windows 透明/置顶/非激活窗口、200% DPI、隐藏页面、审批桥接、页内回退和进程关闭。另以真实隔离浮窗检查任务状态、减少动态效果、悬停/拖动优先级、审批关闭与跟进输入光标。未承诺 macOS/Linux 浮窗或所有旧宿主的原生浮窗行为。
